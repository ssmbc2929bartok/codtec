# 問題データの書き方

問題は `data/langs/` 以下に、1 言語 1 ファイルで置いています。1 行が 1 問です。

## 既存の言語に問題を足す

該当するファイル（たとえば `data/langs/python.js`）を開き、足したいコースの下に 1 行書き足します。

```js
Codtec.register({
    id: 'python',          // 記録の保存に使う名前（あとから変えない）
    name: 'Python',        // 画面に出る名前
    group: 'script',       // メニューでの分類
    words: String.raw`
@@ basics
print("Hello, world!")
n = int(input())

@@ features
squares = [x * x for x in range(10)]  ※ リスト内包表記
`,
});
```

- `@@ コース名` の行から次の `@@` までが、そのコースの問題です。
- 行の途中に `※` を書くと、そこから後ろが解説になり、プレイ中に問題文の下に出ます。解説は省けますが、結果画面の振り返りに出るので、できるだけ付けてください。
- 空行は無視されます。行の前後の空白も取り除かれます。

### コース名

| 書く名前 | 画面の表示 | 入れる問題 |
|---|---|---|
| `basics` | BASICS | 基礎の構文 |
| `stdlib` | STDLIB | 標準ライブラリ・データ構造・組み込みの機能 |
| `features` | IDIOMS | その言語らしい書き方 |
| `advanced` | ADVANCED | 応用・上級者向け |
| `ecosystem` | LIBS | ライブラリ・各界隈の定番 |

使わないコースは書かなくてかまいません。

### 問題文の決まり

- 半角の英数字と記号だけで書きます（キーボードでそのまま打てる文字）。
- 1 問は 56 文字までです。
- 同じ言語の中で、同じ問題は 1 回だけ書けます。
- `ll` や `np` のような別名や省略形を使う問題は、それが何の別名かを解説に書きます。解説に書いてあれば、定義なしで使ってかまいません。
- `\n` などのバックスラッシュは、そのまま書けます（`String.raw` の中なので、二重にしません）。
- 次の 2 つだけは、前にバックスラッシュを付けます。

| 出したい文字 | 書き方 |
|---|---|
| `` ` ``（バッククォート） | `` \` `` |
| `${` | `\${` |

決まりに合わない行は読み込み時に除かれ、ブラウザのコンソールに警告が出ます。

## 言語を足す

1. `data/langs/` に新しいファイルを作り、上の形で `Codtec.register()` を書きます。
2. `data/manifest.js` の一覧に、ファイル名（`.js` を除いた部分）を 1 行足します。

`group` に書ける名前は `systems`、`app`、`script`、`web`、`data`、`tools` です。分類そのものを増やすときは `data/registry.js` の `GROUPS` に足します。

## 検査する

```bash
node tools/validate.mjs
```

言語ごとの問題数と、決まりに合わない行の一覧が出ます。
