> HOW TO PLAY_

01. 遊び方

  1. 言語を選びます。先頭の ALL LANGS を選ぶと、全言語をまたいで出題します。PICK LANGS を選ぶと、言語を押すたびに出題する言語へ入れたり外したりでき、選んだ言語だけから出題します。もう一度 PICK LANGS を押すと、1 言語の選択に戻ります。
  2. コース（出題する範囲）を選びます。
  3. モードを選びます。
  4. 入力のしかた（NORMAL か EDITOR）を選びます。
  5. Enter か MISSION START で開始します。3 カウントのあとに問題が出ます。
  6. 表示されたコードを、左から順にそのまま打ちます。

選んだ言語・コース・モードは保存されるので、次に開いたときも同じ選択から始まります。

02. 入力の決まり

  • 大文字と小文字、記号、スペースを区別します。表示どおりに打ってください。
  • 違うキーを打つとミスになり、その文字が赤くなります。正しいキーを打つまで先へ進みません。
  • スペースが要らない場所で打ったスペースは、ミスに数えません。
  • 日本語入力（IME）はオフにしてください。オンのままだと文字が届きません。

03. コース

PICK COURSES を押すと、複数のコースを選べます。PICK COURSES の間は、コースを押すたびに、出題するコースに入ったり外れたりします。全部選ぶと ALL になります。PICK COURSES をもう一度押すと、1 コースの選択に戻ります。

コースごとに、打ち終えた文字の色が変わります。

コース内容
BASICS基礎の構文
STDLIB標準ライブラリ・データ構造・組み込みの機能
IDIOMSその言語らしい書き方
ADVANCED応用・上級者向け

PICK COURSES自分で選んだ複数のコースから出題

ゲームが終わると、終了の表示が出てから結果画面へ進みます。決めた問題数を打ち切ると FINISH!、持ち時間がなくなると TIME UP!、ミスの上限に達すると TERMINATED です。

06. エディタモード

入力のしかたを EDITOR にすると、エディタのように、開きの括弧や引用符を打ったときに対応する閉じ側が自動で入ります。

  • 対象は ( ) [ ] { } " " ' ' と、バッククォートの対です。
  • 開きを打つと、対応する閉じ側が薄い色で入力済みになります。カーソルがそこに来ると、自動で飛び越えます。
  • 飛び越えた閉じ側を、いつもの癖で打ち直しても、ミスにはなりません。
  • 閉じる相手が問題文の中にない括弧は、ふつうに打ちます。
  • Rust のライフタイム（'a など）が入っている問題では、' を対にしません。
  • 打つキーが減るので、自己ベストは NORMAL と別に保存します。KPM は、実際に打ったキーだけで数えます。

07. 一時停止

プレイ中に Esc か右上の PAUSE を押すと止まります。止まっている間はタイマーが進まず、問題文は隠れます。別のタブやウィンドウに移ったときも自動で止まります。

08. 結果と解説

  • KPM は 1 分あたりに正しく打ったキーの数です。
  • ACCURACY は、打ったキーのうち正しかった割合です。
  • REVIEW には、プレイした問題がコース・ミスの回数・解説つきで並びます。どういう文法やデータ構造なのか、何によく使われるのかを確かめられます。
  • 解説はプレイ中にも、問題文の下に出ます。ll や np のような別名を使う問題では、それが何の別名かも解説に書いてあります。
  • 「結果をシェア」を押すと、結果を X に投稿する画面が開きます。文面は短くするために略して書きます。LANG: Rust +4 は、Rust がいちばん多く出て、ほかに 4 言語から出題されたことを表します。COURSE は出題されたコースの略称で、BAS は BASICS、STD は STDLIB、IDM は IDIOMS、ADV は ADVANCED、LIB は LIBS です。5 つすべてが出たときは ALL と書きます。[NEW] は自己ベストの更新です。

09. 背景

画面左下の BG ボタンを押すたびに、背景が PLAIN（無地）、GRID（方眼）、CIRCUIT（基板）、CRT（走査線）の順に切り替わります。選んだ背景は保存されます。

PLAIN 以外の背景では、MARATHON と SUDDEN DEATH の間、10 問クリアするごとに背景がワープして、次の見た目に変わります。ワープの間は、模様が一気に拡大してから新しい細かさに落ち着き、色が次の色へ移り、中心から外へ光の筋が走ります。進むほど、模様は細かく、明るくなります。ワープとワープの間は、背景は動きません。OS で「視差効果を減らす」を選んでいるときは、ワープの動きを出さず、見た目だけを切り替えます。

10. 警告と停止の演出

MARATHON と SUDDEN DEATH だけで出る演出です。ほかのモードと CUSTOM では出ません。

  • MARATHON で残りが 10 秒以下になると、画面の縁が橙に脈打ち、タイマーの色が変わり、背景がゆっくり鼓動します。
  • 残りが 5 秒以下になると、縁とタイマーが赤くなって点滅し、背景が小刻みに揺れます。問題をクリアして時間が増えると、警告は消えます。
  • MARATHON で時間切れになったときと、SUDDEN DEATH でミスしたときは、画面が赤く明滅してシステムが止まる演出が出ます。結果画面も、赤く沈んだままになります。
